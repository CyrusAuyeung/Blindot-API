# Security Policy

## Reporting A Security Issue

Please report security issues privately through GitHub Security Advisories when possible.

Do not disclose exploitable details in public issues before the issue has been reviewed.

## Scope

This repository contains deployment configuration, documentation, and the smtp2brevo relay source code.

Useful reports include:

- Affected file or component
- Reproduction steps
- Expected and actual behavior
- Potential impact
- Suggested mitigation, if available

## Secret Handling

Do not include API keys, private keys, database dumps, real environment files, or runtime data in issues or pull requests.
